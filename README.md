# Inkbox Claude Gateway – Home Assistant Add-on

Home-Assistant-Add-on, das den
[Inkbox-Gateway für Claude Code](https://github.com/inkbox-ai/claude-code-plugin)
dauerhaft laufen lässt. Claude antwortet damit auf E-Mails und iMessages an deine
Inkbox-Identität.

[![Repository zu Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Ffvh02%2Ffabiaiagent)

Oder manuell: *Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories* →
`https://github.com/fvh02/fabiaiagent`.

Installation, Einrichtung und Fehlersuche:
[`inkbox_claude_gateway/DOCS.md`](inkbox_claude_gateway/DOCS.md).

Zugangsdaten gehören ausschließlich in den Konfigurations-Tab des Add-ons, nie in
dieses Repository.
